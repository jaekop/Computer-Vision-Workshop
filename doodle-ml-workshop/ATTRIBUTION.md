# Data and libraries

The workshop uses a small sample of the Google Quick, Draw! bitmap dataset:
https://github.com/googlecreativelab/quickdraw-dataset

Quick, Draw! drawings are made available by Google under CC BY 4.0. Credit:
"Quick, Draw! Dataset — Google Creative Lab". Check the official dataset
documentation before redistributing prepared data.

This repository contains original instructional code and SVG drawings.
Third-party packages are installed via requirements.txt and retain their
respective licenses.
